# Security

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Chernoplodich/Veylume/security/advisories/new). If that form is unavailable, open an issue asking for a private reporting channel without posting the vulnerability details.

Include the app version, macOS version, affected feature, impact, and a minimal reproduction using non-private test data. Never send passwords, signing keys, Keychain exports, personal recordings, or transcripts.

Only the latest preview receives fixes. A report is not an agreement to a response deadline or a bug-bounty payment.

## По-русски

Об уязвимости лучше сообщить через [закрытую форму GitHub](https://github.com/Chernoplodich/Veylume/security/advisories/new). Если она недоступна, создайте Issue с просьбой предоставить закрытый канал связи, без технических подробностей уязвимости.

Укажите версию приложения и macOS, затронутую функцию, возможные последствия и воспроизведение на тестовых данных. Не отправляйте пароли, закрытые ключи, экспорт Связки ключей, личные записи и диктовки. Исправления выпускаются для последней предварительной версии.
