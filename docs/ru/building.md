# Сборка из исходников

[English](../building.md) · **Русский** · [На главную](../../README.ru.md)

## Среда разработки

Нужны Mac с M-чипом, Swift 6.2 или новее и macOS SDK. Установите Xcode либо Command Line Tools. Разработка проверялась со Swift 6.4 и SDK 27; полноценный Xcode archive и запуск на всех более ранних поддерживаемых версиях macOS пока не проверены.

```sh
git clone https://github.com/Chernoplodich/Veylume.git
cd Veylume
bash scripts/bootstrap-dependencies.sh
bash scripts/test.sh
bash scripts/build.sh release
```

Готовое приложение появится в `artifacts/Veylume.app`. Обычному пользователю для запуска не нужны Swift, Python, Homebrew и другие инструменты разработки.

Чтобы установить свою сборку, завершите запущенную Veylume и выполните:

```sh
bash scripts/install-local.sh
```

По умолчанию используется `~/Applications/Veylume.app`. Смена локальной подписи может потребовать повторно выдать системные разрешения.

## Зависимости и модели

Версии Swift-зависимостей закреплены в `Package.resolved`. Подготовка скачивает конкретные бинарные зависимости и проверяет SHA-256. Для моделей закреплены ревизии и хеши файлов. В исходниках нет весов моделей, личных записей, локальных баз данных, профилей подписи и закрытых ключей.

Parakeet V3 устанавливается обычным первым запуском. Не включайте собственную папку Application Support в дистрибутив.

## Подпись и DMG

Без локального профиля используется ad-hoc подпись. Скрипт `scripts/setup-local-signing.py` позволяет создать постоянную личную identity для разработки на своём Mac. Это не Developer ID от Apple и не нотариализация. Локальный профиль и закрытый ключ не должны попадать в Git.

Для создания образа:

```sh
python3 -m venv .build/dmg-tools
.build/dmg-tools/bin/pip install dmgbuild==1.6.7
bash scripts/package.sh
```

После упаковки `package.sh` монтирует образ только для чтения и проверяет подпись и содержимое приложения. Отдельный `release.sh` готовит подписанный Developer ID и нотариализованный выпуск; для этого нужны настоящие данные разработчика и конфигурация обновлений. Сам скрипт ничего публично не загружает.

Основные правила работы с записью и вставкой — в [Contributing](../../CONTRIBUTING.md).
