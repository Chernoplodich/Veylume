# Установка Veylume

[English](../installation.md) · **Русский** · [На главную](../../README.ru.md)

## Что понадобится

Mac с M-чипом и macOS 14 или новее. Для дополнительной модели Cohere нужна macOS 15 или новее. Intel пока не поддерживается.

Помимо приложения, понадобится около 483 МБ для базовой модели. При первом скачивании нужен интернет. Прогресс отображается в Veylume; перед использованием загруженные файлы проверяются.

## Установка

1. [Скачайте DMG](https://github.com/Chernoplodich/Veylume/releases/latest/download/Veylume-arm64.dmg).
2. Перетащите **Veylume** в **«Программы»**. Если раньше вы установили её в `~/Applications`, используйте эту же папку.
3. Извлеките образ диска и откройте установленное приложение. Оставьте одну рабочую копию.

## Первое открытие

В предварительной версии пока нет подписи Developer ID и нотариализации Apple. Поэтому macOS может сообщить, что разработчик не проверен.

Если файл скачан из этого репозитория и вы доверяете выпуску, сначала попробуйте открыть установленную Veylume. Затем перейдите в **«Системные настройки → Конфиденциальность и безопасность»**, найдите сообщение о Veylume и выберите **«Всё равно открыть»**. Подтвердите системный диалог самостоятельно. [Инструкция Apple](https://support.apple.com/ru-ru/102445).

Не отключайте Gatekeeper, не снимайте карантин командами в терминале, не устанавливайте корневой сертификат и не импортируйте чужой закрытый ключ. Если система сообщает, что приложение повредит компьютер или было изменено, остановитесь и сообщите точный текст предупреждения.

## Настройка перед первой записью

Parakeet V3 готовится автоматически, пока вы проходите настройку. Сравнивать и выбирать модели для начала работы не нужно.

- **Микрофон.** Разрешите доступ в диалоге macOS. Запись включается только по вашей команде.
- **Вставка и клавиши.** Откройте из Veylume раздел Accessibility («Универсальный доступ») в настройках приватности, включите установленную копию и вернитесь в приложение. Кнопка «Проверить доступ» покажет результат. «Мониторинг ввода» запрашивается только при необходимости для выбранного способа обработки клавиши.
- **Локальное хранилище.** Ключи шифрования хранятся в Связке ключей macOS. Если появится системный запрос, вводите пароль только в этом окне. В самой Veylume формы ввода пароля нет.
- **Клавиша записи.** Назначьте удобное сочетание для удержания. Позже можно добавить отдельную клавишу для начала и остановки по нажатию.

Поставьте курсор в поле ввода и произнесите короткую фразу. Если доступ к вставке пока недоступен, настройку можно закончить с ручным копированием результата.

## Обновление

Завершите Veylume через её меню. Скачайте новый DMG, замените приложение в той же папке и откройте снова. Не запускайте параллельно копию с образа диска. Модели, настройки и локальные данные сохраняются отдельно и останутся на месте.

Автоматического канала обновлений в предварительной версии нет. После смены сборки macOS может повторно попросить подтвердить доступ.

## Если диктовка не сработала

Убедитесь, что модель готова, а горячие клавиши не приостановлены. Проверьте, что запущена одна установленная копия. Поставьте курсор в нужное поле и оставьте его там до результата. Поле пароля может включить Secure Input — выйдите из него перед новой записью.

При недоступной вставке откройте «Последний результат → Скопировать». Enter приложение не нажимает. [Сообщить об ошибке](https://github.com/Chernoplodich/Veylume/issues/new/choose) можно с версией Veylume, macOS и названием приложения, без личных текстов и записей.
